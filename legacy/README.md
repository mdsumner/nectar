# legacy

Notes from about 2014 to 2023, kept as they were written. They're out of date
(Ubuntu 14.04–22.04, R 3.5, the old Nectar dashboard layout, Raijin, Murano)
and they aren't instructions. The guide in [`../guide`](../guide) replaces them.

Some of them fed the guide:

| File | Mined into |
|------|------------|
| `README-2014.md` | `guide/01-concepts.md`, `guide/04-launch-a-vm.md` |
| `openstack/create_install_rstudio_openstack.md` (plus [issue #14](https://github.com/mdsumner/nectar/issues/14)) | `guide/06-rstudio-server.md` |
| `r-spatial.md`, `eratos_r.md` | `guide/07-software.md` |
| `docker/`, `miscellaneous/rocker.sh` (plus [issue #10](https://github.com/mdsumner/nectar/issues/10)) | `guide/07-software.md` |
| `miscellaneous/metadata.md` | `guide/08-looking-after-it.md` |

The rest are one-off recipes for particular software (Atlantis, CGAL, KEA,
PostGIS, pytroll, ROMS, MATLAB, ECW, HDF4, GDAL source builds, ...). They're
here in case someone needs them again.
